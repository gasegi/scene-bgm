# Scene BGM

フリーBGMを「場面・雰囲気」から選んで連続再生する、自分用のブラウザプレイヤー。

- 場面カードを1タップ、または検索1回でセットリストを作って再生
- シャッフル / リピート（全曲・1曲・オフ）/ キューの並べ替え
- 再生履歴から、あとでお気に入り登録できる
- お気に入りは端末のブラウザに保存。JSONの書き出し・読み込みで別の端末へ移せる
- ダーク / ライト / 端末に合わせる のテーマ切り替え

## 音源について

- 再生は **YouTube 公式動画の埋め込み** のみ。素材サイトの音源ファイルには直接アクセスしない
  （OpenTracks・甘茶の音楽工房は直リンク禁止、魔王魂はサーバー側で直リンクを拒否しているため）
- アプリは実行中に素材サイトのサーバーへアクセスしない。曲情報は `data/*.json` に同梱
- 現在の収録：魔王魂のBGM（YouTube動画のある360曲）

## 曲情報の更新

```bash
node scripts/build-catalog.mjs
```

魔王魂の一覧ページを1.5秒間隔で取得して `data/maou.json` を作り直す。
サーバー負荷を避けるため、定期実行はせず必要なときに手動で行う。

## ローカルで動かす

```bash
node scripts/serve.mjs 5173
```

同じWi-Fiのスマホからは、表示される `http://192.168.x.x:5173/` を開く。

## 構成

ビルド不要の静的サイト（GitHub Pages にそのまま置ける）。

- `index.html` / `style.css` / `app.js` — アプリ本体
- `data/maou.json` — 曲情報
- `scripts/build-catalog.mjs` — 曲情報の収集
- `scripts/serve.mjs` — 開発用サーバー
